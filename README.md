# 集團財務追蹤平台（廠商/應付/支出/付款）

四間分公司（興聖、容鴻、芙萊柏、海濤客）共用一個網站，右上角可一鍵切換公司；
資料來源是人工從鼎新A1匯出的 Excel，上傳到「匯入資料」頁即可。僅供內部人員以帳號密碼登入，
沒有對廠商開放的功能。

## 登入保護開關（部署設定期間可先關閉）

環境變數 `REQUIRE_LOGIN` 控制要不要強制登入：
- `REQUIRE_LOGIN=false`（目前預設）：任何人打開網址都能直接使用，不需要帳號密碼。**只適合在還沒設定好、只有你自己在測試的階段用**，網址如果外流任何人都能看到公司財務資料。
- `REQUIRE_LOGIN=true`：恢復要求登入，沒登入會被導去 `/login`。

等你確認網站在 Render 上跑起來沒問題、四個公司的資料也匯入測試過之後，記得回 Render 的 Environment 分頁，
把 `REQUIRE_LOGIN` 改成 `true`（或直接刪掉這個變數，因為程式預設就是先給 false，所以**一定要記得手動改成 true**），
存檔後 Render 會自動重新部署，之後就需要登入才能看到資料了。改之前別忘了先執行 `create_admin.py` 建立好帳號，不然改完會登不進去。

## 本機測試

```bash
pip install -r requirements.txt --break-system-packages   # 或用虛擬環境
cp .env.example .env      # 本機測試可以不改，會自動用 sqlite

# 建立第一個登入帳號
python create_admin.py finance 你的密碼 財務部

# 啟動
python app.py
```
瀏覽 http://localhost:8080 ，會自動導去登入頁。

## 部署到 Render

1. 在 Render 開一個 **PostgreSQL** 免費資料庫，複製它的 Internal Database URL。
2. 開一個 **Web Service**，指向這個 repo：
   - Build Command：`pip install -r requirements.txt`
   - Start Command：`python app.py`
3. 環境變數設定：
   - `DATABASE_URL`：貼上第 1 步的 Postgres URL
   - `STORAGE_SECRET`：隨便一組長亂碼（登入 session 加密用）
4. 部署完成後，用 Render 的 Shell 執行一次：
   ```bash
   python create_admin.py finance 你的密碼 財務部
   ```
   之後就可以用這組帳密登入。
5. 之後同事只要把 A1 匯出的四種 Excel，登入後上傳到「匯入資料」頁即可。

## 各模組匯入行為說明（重要）

| 模組 | 匯入方式 | 說明 |
|---|---|---|
| 廠商資料 | Upsert（以廠商代號比對） | 不會刪舊資料，重複匯入會更新既有廠商，新的廠商會新增 |
| 應付帳款明細 | **整批覆蓋** | 每次匯入視為該公司「當下最新快照」，會先清空該公司舊資料再匯入。適合「應付帳款明細表」本來就是列出目前未沖銷項目的情境 |
| 其他支出明細 | 整批覆蓋 | 同上。這張表 Excel 本身沒有「是否已付款」欄位，`is_paid` 匯入後預設為未勾選，需要在畫面上手動勾 |
| 付款明細 | 整批覆蓋 | 同上 |

如果之後發現「應付帳款明細表」其實是持續累積、不該被覆蓋（例如它只匯出當月新增的），
跟我說一聲，把匯入邏輯從「先刪除再新增」改成「只新增不刪除」即可，改動不大。

## 未付金額統計的限制

付款明細表沒有發票號碼欄位，所以系統沒辦法把「一筆應付帳款」跟「一筆付款」逐筆對起來，
只能做到「廠商層級」的加總比對（該廠商應付總額 - 該廠商已付總額 = 估計未付金額）。
儀表板頁面已經在畫面上加註這個限制，避免誤判為精確逐筆勾稽。

## 目錄結構

```
app.py              # 入口，設定路由
database.py          # DB 連線 / 建表 / 塞入四間公司
models.py             # 資料表結構
auth.py                # 登入密碼雜湊/驗證
create_admin.py          # 建立登入帳號的小工具
importers/                # 四個模組各自的 Excel 匯入邏輯
pages/                      # 四個模組的畫面 + 儀表板 + 登入頁 + 共用頁首(公司切換)
```

## 之後可以擴充的方向

- 廠商資料的「智慧自動帶出」：目前應付/付款明細匯入時已經會用廠商名稱自動關聯到廠商主檔（`vendor_id`），
  未來可以在新增/編輯畫面加上「輸入廠商關鍵字自動帶出聯絡人/電話/匯款帳號」的下拉搜尋元件。
- 目前登入是單一角色（內部人員），如果之後要開放不同權限（例如只能看自己公司），
  可以在 `users` 表加一個 `company_id` 欄位做限制。
- 「請款期限提醒」「發票補件提醒」等功能還沒實作，可以之後在廠商主檔加「月結天數」欄位後接上。
